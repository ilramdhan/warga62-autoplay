## Melaporkan kerentanan

Jangan membuka issue publik untuk kerentanan. Laporkan lewat [GitHub Security Advisories](https://github.com/ilramdhan/warga62-autoplay/security/advisories/new) dengan tombol **Report a vulnerability**. Sertakan:

- Deskripsi kerentanan dan dampaknya.
- Langkah untuk mereproduksi.
- Versi dan lingkungan yang dipakai (extension atau runner, versi Chrome, dan sistem operasi).

Kami akan berusaha merespons secepat mungkin.

## Profil browser

Folder `.runner-profiles` berisi profil browser dengan cookie login. Jangan pernah membagikan, mengunggah, atau melampirkan folder ini ke issue, pull request, maupun laporan keamanan.

## Kerentanan di game Warga +62

Repositori ini hanya berisi bot. Kerentanan di game itu sendiri harus dilaporkan langsung ke developer game. Jangan mengeksploitasinya, dan jangan menerbitkan detail teknisnya di repositori publik, issue, atau media sosial.
