# Pencapaian & otomatisasi

Katalog lengkap ada di `src/core/data/achievements.js` (51 pencapaian). Planner (`src/core/strategy/planner.js`) memilih
target, lalu menghasilkan **preset room** dan **flag policy** yang dibaca `grind.js` / `smart.js`.

## Hal penting

- Juara 1 selalu Negara. "Menang" di game ini berarti **Juara 2**.
- Pencapaian Juara 2 hanya dihitung kalau game berjalan **minimal 10 ronde**. Karena itu, di mode grind
  feeder diberi flag `holdBankruptUntilRound: 10`: sebelum ronde 10 feeder menyisakan kas secukupnya, meminjam
  ke pemenang (bunga 0%) atau Pinjol, dan baru boleh bangkrut setelah ronde itu.
- Room selalu **Privat** (atau **Teman** bila diminta). Planner tidak pernah menghasilkan akses Publik.
- Kabur/AFK tidak membuka pencapaian apa pun, jadi bot harus menyelesaikan game sampai layar hasil.
- Dadu tidak bisa diatur. Pencapaian yang bergantung pada nasib (Lapas, kembar, sewa besar) hanya bisa
  "dibantu" (game lebih panjang, zona Perfect/Cupu, Joki Dadu), tidak dijamin.

## Cara planner memilih target

1. Kalau `config.achievements.targets` diisi, target itu dipakai apa adanya.
2. Kalau kosong: ambil pencapaian yang belum selesai (dari progres profil), cocok dengan mode
   (`grind` / `arena` / keduanya), dan syarat akunnya terpenuhi (mis. 8 akun untuk Menang di Kondangan).
   Urutan prioritas: Juara 2 → satu game → hitungan → total. Maksimal 3 target per game (`maxTargets`).
3. Target yang bentrok ditunda dan dicatat di `notes`, contoh: Pinjol tidak ada di Krismon, `rollTarget`
   Perfect vs Cupu, "tahan bangkrut" vs "Bangkrut Sebelum Gajian", wantJail vs wantBail.
4. Tugas mingguan (Kerja Bakti) berganti tiap Senin, jadi teksnya dicocokkan dengan `WEEKLY_TASK_PATTERNS`
   (mis. "Ambil Pinjol 2 kali" → `wantPinjol`, "Lempar Perfect 5 kali" → `rollTarget: 'perfect'`,
   "Masuk Lapas 3 kali" → `wantJail`). Teks yang tidak dikenali dicatat di `notes`.
5. Preset akhir: nilai dari `config.room`, ditimpa preset target (kalau `room.autoByAchievement` tidak `false`).
   Mode Ronde selalu dibulatkan ke 10/15/20 dan minimal sama dengan `minRounds`. Peta `cycle` diganti peta
   Turis Domestik yang belum pernah diselesaikan.

Flag di bawah kunci `winner` / `feeder` hanya berlaku untuk peran itu di mode grind. Di mode arena, flag
`winner` berlaku untuk akun itu sendiri dan flag `feeder` diabaikan.

## Perlu langkah manual

- **Tim Sukses** (referral) dan **Rebut Dadu Developer** (butuh developer di meja): tidak diotomatisasi.
- **Nambah Relasi**, **Circle Mabar**, **Grup Arisan**: pertemanan antar akun dibuat sendiri sekali; setelah itu
  game-nya bisa otomatis.
- **Menang di Kondangan**: butuh 8 akun sendiri yang ikut main.
- Pencapaian rahasia selain "Bangkrut Sebelum Gajian" syaratnya masih dugaan dari petunjuk. Flag-nya
  bersifat eksperimental; cek hasil di profil setelah beberapa game.

## Asumsi untuk modul lain

- Progres pencapaian dibaca handler `profile-sync` (bukan modul ini) dan diberikan ke planner dalam bentuk
  `{ [id]: { done, progress?, mapsDone? }, weekly?: [{ text, done }] }`.
- Host yang menerapkan `roomPreset` lewat modal "Atur" (termasuk `rounds` 10/15/20 untuk mode Ronde).
