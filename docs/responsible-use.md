# Gunakan dengan bijak

Proyek ini adalah alat bantu untuk bereksperimen dengan akun milik sendiri. Dengan memakainya, kamu setuju mengikuti poin-poin berikut.

## Batasan penggunaan

- Hanya gunakan akun milik sendiri.
- Hanya bermain di room privat atau room teman yang kamu buat sendiri.
- Jangan pernah memakai bot di room publik, atau melawan orang lain tanpa izin mereka.
- Jangan memakai bot untuk mengganggu pemain lain, atau untuk menghindari deteksi anti-bot.

## Hormati developer game

Warga +62 adalah game indie kecil yang didukung donasi pemainnya. Jika kamu menikmati game ini, pertimbangkan untuk mendukung developer-nya.

## Risiko

Menggunakan bot dapat melanggar ketentuan layanan game dan bisa berakibat akun dibekukan atau dihapus. Risiko ini sepenuhnya ditanggung pengguna.
